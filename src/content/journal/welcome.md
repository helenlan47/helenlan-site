This is a placeholder journal entry so you can see the format.

Every post lives in `src/content/journal/` as its own markdown file. The
frontmatter at the top (title, date, description, tags) drives the listing
page and each post's URL is just the filename — this one is `/journal/welcome`.

Delete this file once you've written your first real entry, or keep it
around as a "start here" post.

You can write in normal markdown: **bold**, *italic*, [links](https://example.com),
lists, images, etc.
